## Run locally

Open `index.html` in any modern browser or use a local static server.

## Publish on GitHub Pages

1. Create a public repository named `royal-bites-restaurant`.
2. Upload the contents of this folder to repository root (the `index.html` file must be in the root).
3. Go to **Settings → Pages → Build and deployment**.
4. Set **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. The site becomes available at the live site URL after deployment succeeds.
